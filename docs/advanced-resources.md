# Additional anatomical resource assessment

This assessment concerns datasets that could provide detail beyond the registered Digimouse label inventory. It is a source review, not an import report. No assets from the resources below were incorporated, and no model archive or mesh body was downloaded for this assessment. The active atlas manifest remains the authority for implemented coverage. Source pages and metadata were reviewed on 26 October 2026.

## Allen regional brain anatomy

The [official Allen CCF directory](https://download.alleninstitute.org/informatics-archive/current-release/mouse_ccf/annotation/ccf_2017/) provides individual OBJ files under `structure_meshes`. The [AllenSDK reference-space example](https://allensdk.readthedocs.io/en/latest/_static/examples/nb/reference_space.html) identifies structure 1011 as Dorsal auditory area, 247 as Auditory areas and 385 as Primary visual area. Each corresponding filename appears in the [official mesh index](https://download.alleninstitute.org/informatics-archive/current-release/mouse_ccf/annotation/ccf_2017/structure_meshes/). Individual file sizes and checksums have not been measured, so none is yet approved against the 5 MB acquisition bound used in this assessment.

The 2017 mesh namespace and the newer Allen-CCF-2020 package must remain distinct. The [dataset-specific Allen-CCF-2020 description](https://raw.githubusercontent.com/AllenInstitute/abc_atlas_access/main/descriptions/Allen-CCF-2020.md) identifies package version `20230630`, reports 379.1 MB of image volumes and 1.18 MB of metadata, and explicitly directs users to the [Allen Institute Terms of Use](https://alleninstitute.org/legal/terms-of-use). Those terms permit research and other noncommercial copying, adaptation and redistribution subject to their conditions; commercial redistribution requires written permission. This is not a verified CC BY 4.0 grant for that CCF package. Licenses on other Allen datasets or on access software cannot be transferred to these anatomical data. No separate, more permissive grant for the selected 2017 OBJ files was verified here.

The CCF reference is an average adult C57BL/6J brain rather than the Digimouse specimen. Its documented volume orientation is anterior to posterior, superior to inferior and left to right; a mesh's units and coordinates still need direct inspection. A labelled brain atlas cannot be placed into a body atlas by an assumed scale, rotation or bounding-box fit. Until an accepted registration exists, a future import should be an independently identified brain reference with its own frame and specimen description. Parent and child anatomical meshes can overlap; their volumes must not be summed as disjoint structures.

Reference: Wang Q et al. The Allen Mouse Brain Common Coordinate Framework: A 3D Reference Atlas. *Cell*. 2020;181(4):936-953.e20. [doi:10.1016/j.cell.2020.04.007](https://doi.org/10.1016/j.cell.2020.04.007).

## Small cellular morphology candidate

The primary Janelia Figshare record [MouseLight Neuron AA1624](https://janelia.figshare.com/articles/dataset/MouseLight_Neuron_AA1624/27766452) lists Mary Lay, Tiago Ferreira and the MouseLight Project Team, a reported download size of 1.1 MB, and CC BY 4.0. It is a promising selective morphology candidate. The indexed primary record was available, but direct page and API access did not provide a file listing during this review. Exact byte counts, file format, record version, checksum and coordinate metadata therefore remain unverified; the model itself was not downloaded.

[MouseLight's methods resource](https://www.janelia.org/project-team/mouselight/resources) describes traced single-neuron reconstructions from sparsely labelled brain samples, registered to an Allen reference. This does not establish a transform to Digimouse or a particular CCF release for AA1624. A single reconstruction would support a documented cellular morphology view, not complete cellular coverage, observed synapses or functional connectivity. Raw whole-brain microscopy is unnecessary for that bounded use and is unsuitable for the initial storage budget.

Project methods reference: Winnubst J et al. Reconstruction of 1,000 projection neurons reveals new cell types and organization of long-range connectivity in the mouse brain. *Cell*. 2019;179(1):268-281. [Janelia publication record](https://www.janelia.org/publication/reconstruction-of-1000-projection-neurons-reveals-new-cell-types-and-organization-of), [doi:10.1016/j.cell.2019.07.042](https://doi.org/10.1016/j.cell.2019.07.042). This project-level paper is not an independent validation of a later individual deposit.

## Embryonic and musculoskeletal sources

The verified eMouseAtlas records are developmental references. [EMA147](https://datashare.ed.ac.uk/items/5016a5d4-2017-4fdc-a934-964fc2b542ec/full) is an MRI-derived TS23 embryo at an estimated E15.0 and has a CC BY 4.0 surface archive reported as 10.87 MB. [EMA108](https://datashare.ed.ac.uk/items/431e48dd-d970-47e0-ac82-ea799dc90bf3/full) is an OPT-derived forelimb reference at TS23/E14.5, with CC BY 4.0 and a reported 17.34 MB surface archive. Both whole archives exceed the current 5 MB acquisition bound. No adult segmented whole-body replacement was identified in this bounded eMouseAtlas review. Embryonic structures must not be silently represented as adult anatomy.

The primary paper [A Whole-Body Musculoskeletal Model of the Mouse](https://pmc.ncbi.nlm.nih.gov/articles/PMC8865483/) describes independently represented skeletal elements and modelled limb musculature. Its stated [resource repository](https://gitlab.com/paper_submissions/mouse_biomechanics_paper) was reachable, but a model-asset license, complete file inventory, pinned release and selective file sizes were not established. The article's CC BY 4.0 license is not sufficient evidence for separate mesh files. This remains a candidate for asset-provenance review, not a licensed anatomical import. Its generic, multi-source construction and modelling assumptions also preclude treating it as measured anatomy of the Digimouse specimen.

Reference: Tata Ramalingasetty S et al. A Whole-Body Musculoskeletal Model of the Mouse. *IEEE Access*. 2021;9:163861-163881. [doi:10.1109/ACCESS.2021.3133078](https://doi.org/10.1109/ACCESS.2021.3133078).

## Adult bony labyrinth surface candidate

[MorphoMuseuM dataset e220](https://www.morphomuseum.com/articles/view/220), published on 15 January 2024, supplies paired mouse inner-ear surfaces. Its named deposit M3#1376, [doi:10.18563/m3.sf.1376](https://doi.org/10.18563/m3.sf.1376), represents the two bony labyrinths of specimen SW0ter. The [specimen record](https://www.morphomuseum.com/specimens/view/1172) describes an adult male Swiss laboratory mouse. This is a narrow sensory and skeletal anatomy candidate, not a complete skull or skeleton. The [repository's explicit 3D-data license statement](https://www.morphomuseum.com/) is CC BY-NC 4.0, so redistribution must respect its noncommercial restriction. Individual file size, format, checksum, acquisition resolution, units and source-file version were not established, and no model was downloaded. No registration to Digimouse is known.

Data authors: Sabrina Renaud, Léa Amar, Caroline Romestaing, Jean-Pierre Quéré and Renaud Lebrun. Dataset article: [doi:10.18563/journal.m3.220](https://doi.org/10.18563/journal.m3.220).

## Conditions for the next selective import

A small-file import should first verify the individual resource's applicable terms, source release, file list, expected byte count and checksum. A response without a trustworthy size must be streamed with an enforced byte cap. This review authorizes no automatic acquisition of a complete atlas package. Preserve original source IDs and coordinate data, inspect actual geometry and biological coverage, and record a separate source frame before offering the content in the viewer.

The next decision is between an independent regional brain reference subject to Allen's specific use conditions and a small, permissively licensed single-neuron morphology after file-level verification. A narrow adult inner-ear surface source is available under noncommercial terms; more complete skeletal anatomy still requires a separately licensed and documented mesh source. None of these candidates currently supplies a verified registration to Digimouse. The [resource registry](../data/resource-registry.json) records these decisions and unknown fields explicitly.
