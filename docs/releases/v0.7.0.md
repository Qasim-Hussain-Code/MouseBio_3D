# MouseBio_3D v0.7.0

## Composable source display layers

Compose source layers combines existing groups from one selected anatomical reference. Overlapping regions occur once, with selected regions opaque. Other regions can be hidden or faded to the smaller of source-default opacity and 15 percent. Already translucent source defaults remain lower. The action retains observations, their provenance, background and mode; restores base surfaces, clears clipping and frames the selected bounds while retaining camera direction and roll.

The source-group checklist stages an action and clears after application. Saved views preserve the resulting selection, visibility, opacity and optional camera pose with the existing atlas, asset and frame binding. They do not store a layer hierarchy or temporary checkbox choices. Show all restores source defaults. No geometry, source ID, coordinate unit, spatial registration, experimental-data format or saved-view schema is changed.

EMA147 adds four narrow selections: 75 named surfaces excluding skin and the unannotated reference; 15 selected neural-labelled surfaces; six filenames explicitly naming bone or cartilage; and eight explicit tissue/layer labels. These selections may overlap and are not formal system classifications or complete organ inventories. Other skeletal labels are omitted from the narrow bone/cartilage selection. No identity is assigned to the reference surface, and no mineralization, laterality, biological connectivity or microscopic reconstruction is inferred.

A separate cellular source assessment records version-specific Figshare AA1624 metadata and distinguishes its deposit license from NeuronBrowser terms. Neither morphology body has been acquired and no cellular geometry is implemented by this release. Coordinate units, individual specimen and CCF release remain unresolved for that candidate.

## Verification and limits

All 177 JavaScript and simulated DOM cases and all 64 Python cases passed without failures or skips. The TypeScript production build, dependency notice check and all seven HTTP distribution checks passed. New cases cover unions, overlap, all four source namespaces, context opacity, invalid requests, immutable output and retained observations and saved display settings. Existing geometry and source bindings remain unchanged.

Checks ran in a local WSL temporary copy whose source, tests, configuration and asset hashes are checked against the workspace before publication. The conservative resource estimate includes ignored local sources, tools, dependencies, caches, intermediates, release artifacts, Git metadata and the full WSL temporary-filesystem capacity against 10 GB. It does not inspect NTFS alternate data streams or follow symbolic links and is not a precise allocated-size measurement.

The publication scan on the Windows-mounted checkout was interrupted during slow Git filesystem reads. The same checker runs against a native WSL review snapshot whose file bytes and modes are verified against the staged Git blob identities; current author and committer identities are checked separately. Sanitized publication history receives its own review.

Actual browser pixels, pointer interaction, occlusion, responsive layout and representative GPU performance remain unverified. Numerical source checks do not establish independent anatomical accuracy, physical calibration or physiological validation. EMA147 mesh units remain unknown. All references retain their separate frames and licenses.
