# v0.17.1 release packaging of the living mouse

This release contains the application of [v0.17.0](v0.17.0.md) unchanged. The release packager did not accept the TypeScript scripts that build the living mouse model, so v0.17.0 has a tagged source tree but no release archives. The packager now accepts them, and a new test checks every tracked path of the repository against it.

## Executed verification

The Python release suite passed, including the new test on the actual tree. No application code or model data changed.
