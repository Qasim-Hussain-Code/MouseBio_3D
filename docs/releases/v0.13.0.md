# v0.13.0 prototype candidate

The prototype now provides guided entry points to the existing organ, brain, hindlimb, vessel, nerve and single-neuron references, an explicitly requested fictional comparison walkthrough and an independent parameterized mouse ventricular-cell simulation. [The prototype guide](../prototype-guide.md) describes the complete current application, setup, data formats, privacy, licenses and limits.

## Implemented behavior

- Eight reviewed starting views select existing source groups in their own coordinate frames. Reference adoption retains source-bound observation banks and the viewer background. Failed reads retain the current reference and data.
- The fictional comparison selects and reveals its existing mapped regions. It is unavailable when it would replace observations or an active import. Canceled or superseded reads do not retain a stale import guard. Synthetic provenance survives normalized JSON exports.
- Living includes a 41-state Bondarenko apical ventricular-myocyte equation model at 298 K, separate from surface motion and anatomical references. Local worker calculations provide voltage and two calcium traces, bounded protocols, progress, cancellation, result persistence and JSON/CSV exports with model identity.
- The archived source and optional balanced-transition variant remain explicit. A nonconservative archived sodium-channel transition is documented; its out-of-range states are retained with a warning. The balanced substitution is computationally inferred and lacks independent physiological validation. No state clipping, body-temperature conversion, experimental fitting or spatial registration is added.
- The web ZIP includes `serve_prototype.py`. Run it with Python in Linux or WSL to open the application on loopback without installing Node dependencies. It snapshots only a bounded known web inventory, rejects unsafe filesystem entries and malformed model metadata, serves no launcher/source/research file, and accepts no write methods. Packaging requires the exact executable launcher from the reviewed tracked source.

## Scientific and operational limits

The anatomical assets are unchanged: 28 scientific geometry/line assets totaling 127,939,005 bytes. The equation adaptation adds a separate CC BY 3.0 model and computed numerical reference. Original runtime code remains MIT and original explanatory documentation CC BY 4.0. Each anatomical source retains its existing license and attribution.

The sources do not form a registered complete mouse. Whole-body adult vessels and peripheral nerves, cellular geometry at arbitrary anatomical points, whole-heart conduction, contraction mechanics, blood flow and validated whole-organism physiology remain unavailable. Magnification creates no new biological resolution. Source calibration, orientation, developmental age conflicts, topology defects and uncertainty retain their documented limits. Representative hardware frame rate and memory behavior, remaining browser acceptance cases and independent anatomical and physiological review are not established.
