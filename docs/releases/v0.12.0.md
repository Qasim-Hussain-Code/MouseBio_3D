# MouseBio_3D v0.12.0

## Source path inspection

Source path explorer adds exact source-path lookup, including ID 0, original-order previous and next navigation and pages of at most 20 point records for the regional nerve and cortical vascular references. Every displayed coordinate retains its original number. Vascular endpoints preserve original graph vertex identities and connectivity order, with bounded incident-path navigation. Path rows, original edge IDs, serialized point indices and experimental structure IDs remain distinct. No anatomy, parent tree, missing connection, radius, flow direction or registration is inferred.

Inspect source paths reads only the checked local derivative. A still-live parser-owned asset can be reused through a weak reference without retaining an extra strong source copy. Paging and selection do not refetch or reparse the full source. Failed reads expose fixed messages; reference changes and unmounting cancel pending inspections.

## Focus existing geometry

Focus source path frames only visible retained portions of existing indexed path segments, using current Float32 positions, source path tables, draw range, world transforms and clipping. It retains camera direction and roll. Hidden, transparent, fully clipped or coincident-only paths leave the camera unchanged. Source geometry, background, visibility, opacity, clipping and observations remain unchanged. No marker, surface or completed branch is added.

Inspection selection and graph records remain transient. Saved views may retain the resulting camera pose but contain no inspected records; observation exports remain bound to the complete source structure ID. The source-path read button precedes the longer graph summary in the inspector. See [path inspection methods](../source-path-inspection.md).

## Verification

The source-path integration passed 294 JavaScript and simulated DOM cases, all 111 Python cases with retained originals, dependency notices, TypeScript, the production build and all nine loopback HTTP checks. Actual-source inspection cases cover every nerve path point page, all vascular paths and explicit topology vertices. Focus checks cover source rows, world transforms, recentering, clipping planes, draw range, hidden or coincident geometry, malformed buffers and unchanged source records. Simulated workflows cover explicit reads, zero-based IDs, bounded pages, endpoint navigation, cancellation, fixed errors, camera-focus callbacks, white background and unchanged observations and saved-view records.

All seven bundled references and 28 scientific assets retain their v0.11.0 byte identities, totaling 127,939,005 bytes before manifests and notices. Nerve units remain unknown. Vascular micrometres remain source-declared without independent calibration. Whole-body vascular and peripheral nerve networks, calibrated measurements, accepted anatomical registration and physiological validation remain unavailable. Browser access is unavailable for this review, so graph pixels, pointer behavior, visual layout and representative hardware performance remain unverified.
