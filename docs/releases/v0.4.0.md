# MouseBio_3D v0.4.0

## Functionality

The registered-volume reference now offers original-grid 0.1 mm surfaces for lachrymal and adrenal glands, in addition to the existing 0.2 mm regional surfaces. The two files add 2,060,404 bytes and 85,736 triangles. They preserve source labels 12 and 20 and their existing coordinate frame. No new anatomical structures or tissue detail are inferred.

The inspector provides an explicit processing-level selector for these two regions. Regional requests remain selective. Changing regions, changing references, choosing a source group or accepting a saved view restores base geometry and the default detail level. Compare uses identical base surfaces in both panels. Loading status binds to both structure identity and asset checksum, and changing requests cancels stale loads before the next paint.

Reference cards and Methods display declared specimen and source metadata. Missing attributes remain Unknown. This removes assumptions about sex, age, mass, citation and license from the interface while preserving the two current Digimouse references and their licenses.

The v2 detail index declares processing levels explicitly and covers every region-level pair. The publication checker retains legacy v1 history support and verifies the new assets against their own source snapshot. The bounded converter rejects unsupported native-grid generation before allocating its grid.

## Verification

All 143 JavaScript and simulated interface tests passed in a serialized run. All 46 Python tests and five production HTTP checks passed. The TypeScript production build and dependency notices passed. Both original-grid assets regenerated with identical checksums. The complete resource scan remained below the 10 GB cap. A previous concurrent test run encountered environment SIGBUS and EIO failures and was replaced by the complete passing serialized run.

These tests do not establish actual browser pixels, representative GPU performance, source anatomical orientation, physical calibration or independent anatomical accuracy. Systematic browser and hardware acceptance remain incomplete.
