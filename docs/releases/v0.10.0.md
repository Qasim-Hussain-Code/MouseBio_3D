# MouseBio_3D v0.10.0

## Trace sample navigation

Source sample explorer adds exact sample-ID lookup, source-row navigation, parent inspection and source-ordered child pages of at most 20 IDs. It works with parser-owned local SWC assets and with the checked NMO_130632 numeric derivative after an explicit read. Source tuples, IDs and links remain unchanged. Unknown units, source radius meaning and source type-code limitations remain visible. Experimental observations continue mapping to the complete trace record.

Numerical graph summaries distinguish roots, isolated samples, samples without children and samples with multiple children. These categories do not establish cells, biological completeness, synapses or physiological behavior. Inspector selection and graph records are absent from saved views and observation exports.

## Focus existing source links

Focus incident links frames retained visible portions of the selected sample's existing parent and child links, including children outside the current inspector page. It uses current rendered positions, world transforms and clipping, preserving camera direction and roll. Hidden, fully clipped, isolated and coincident-only selections return a fixed unavailable result. No marker or new geometry is introduced. Background, visibility, clipping and observations remain unchanged.

## Verification

The trace-sample integration passed 247 JavaScript and simulated DOM cases, all 87 Python cases with retained original inputs, dependency notices, TypeScript, the production build and all eight loopback HTTP checks. Numerical source tests cover forward and nonconsecutive IDs, forests, child pagination, exact tuple preservation, parser ownership and a 20,000-sample forward chain. Numerical focus cases cover transformed and recentered geometry, clipping, hidden and coincident links, camera direction and roll, malformed display data and the actual NMO_130632 graph. Simulated workflows cover explicit source reads, cancellation, parent and child navigation, fixed errors, unchanged observations and sample-free saved views. Publication source and archive checks are recorded separately for the reviewed snapshot. Resource accounting remained within the project cap. Actual browser rendering remains unverified: the Windows computer-use runtime stopped when it could not determine the current browser URL for policy enforcement. Numerical and DOM results do not establish pixels, pointer interactions, independent anatomical review, physical calibration or representative hardware performance.
