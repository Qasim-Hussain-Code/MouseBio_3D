# v0.20.0 solid cuts and finer structures

This release continues the [living mouse model](../living-mouse.md), which now holds 176 structures. The source references are unchanged.

## Implemented behavior

- **Cut through the body** in Layers opens a central section. The inner side of each closed surface is drawn in flat colour, so that the cut reads as solid tissue. This is a display convention, and the colours in the cut are the display colours of each structure.
- The coat goes and returns with the Simulated class in **Show by evidence**, so that hiding simulated structures also removes the hair. The highlighted step of the layer stack now follows what is actually shown.
- The structure list is grouped by body system on this reference.
- New simulated structures are the incisors and molars, dorsal root ganglia, sympathetic trunks, cochleae and semicircular canals, and lenses. The CT does not separate teeth from bone, so the teeth are placed in the jaws seen in it.

## Executed verification

All JavaScript and simulated DOM cases passed with no failures or skips, including new cases for the coat following its class, the highlighted step and the section control. TypeScript, dependency notices and the production build passed. The distribution, publication and release suites passed. A headless Chrome session with software WebGL rendered a cut, a view with simulated structures hidden, and the grouped list, without console errors. This is software rendering and not anatomical review.

## Scientific and operational limits

The flat colours in a cut are not measured tissue; the source photographs of the specimen remain available as cut faces on the registered-volume reference. Positions of teeth, ganglia and inner ears are estimates. All limits of the earlier living mouse releases still apply.
