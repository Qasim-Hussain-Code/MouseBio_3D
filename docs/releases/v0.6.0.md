# MouseBio_3D v0.6.0

## Developmental native reference

The application adds eMouseAtlas EMA147 as a separately selected TS23 developmental reference under CC BY 4.0. Its 77 surfaces preserve 76 EMAPA-labelled filenames and one unannotated reference surface. The indexed binary PLY contains 185,779 vertices and all 374,725 source triangles in 10,079,275 bytes. Source winding and coordinates are retained; generated display normals affect shading without repairing geometry.

Physical mesh units are unknown. Numerical scale remains 1, and the image's reported 80 micrometre voxel spacing is not assigned to the surfaces. No metric glTF conversion, anatomical direction, calibrated measurement or cross-reference registration is claimed. Only 23 surfaces meet the executed closed-topology checks; known source defects remain present. The anatomy index and surface inventory match on only 68 EMAPA identifiers, with eight occurring only in each inventory.

The reference displays TS23 with separately attributed E15.0, 15 dpc and 14.5 dpc source estimates. No scalar age is selected. Missing sex, mass and explicit specimen count remain unknown. Source system classifications remain unreviewed. Display groups select existing labelled surfaces, vessel-labelled surfaces, trigeminal-labelled surfaces or the unannotated reference without asserting connectivity. No physiological motion is implemented for this source.

Dark and White backgrounds, source-bound saved views, reference-specific local observations and comparison work with the new reference. Existing Digimouse and hindlimb references retain their separate IDs, frames, methods and licenses. The README describes the complete current application.

## Verification

All 158 JavaScript and simulated DOM cases and all 64 Python cases passed with no failures or skips. The TypeScript production build, dependency notices and all seven production HTTP distribution checks passed. Numerical source checks cover every native triangle and winding, indexed region boundaries, normals and source topology. Actual Three.js loader cases cover all 77 surfaces. Publication and packaging cases include malformed headers, binary layouts, reassigned identities and invented metadata.

Checks ran in a local WSL temporary copy because the Windows-mounted workspace intermittently stalled. Source, test, configuration and asset files are verified against the workspace by SHA-256 before publication. Resource accounting includes ignored source inputs, dependencies, caches, intermediates, release artifacts and Git metadata against the 10 GB cap. A conservative Windows metadata estimate plus the full WSL temporary-filesystem capacity is used when the mounted WSL scan stalls; it does not inspect NTFS alternate data streams or follow symbolic links and is not a precise allocated-size measurement.

These results do not establish actual browser pixels or interactions, representative GPU performance, self-intersection freedom, independent anatomical review, physical calibration or physiological validation.
