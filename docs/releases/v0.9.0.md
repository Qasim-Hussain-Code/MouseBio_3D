# MouseBio_3D v0.9.0

## Independent neuronal source reference

The reference selector adds NeuroMorpho.Org NMO_130632, a source-declared adult mouse V1 layer 4 neuronal reconstruction. The independently identified trace retains 11,650 numeric sample records, all 11,649 explicit parent links, original sample IDs, type codes, coordinates, radius fields and row order. The selectable experimental structure is `neuromorpho:130632`; individual sample IDs remain graph identities rather than separate experimental structures.

The distributed numeric SWC derivative contains no original comment headers or blank lines. These headers include contact and machine information and remain only in the ignored original source. Numeric token spelling is retained, field separators become one ASCII space and rows use LF line endings. The original is 448,329 bytes with SHA-256 `a8340628eb02051416ad0607e72b60cba9241eb34c9be10b0c7df01771b5cfce`. The derivative is 424,092 bytes with SHA-256 `0dd36d6518aacd6338d16c76318d6ed0fd24419a0551417fdf639a8323c6ede5`. Source publication, repository and CC BY 4.0 attribution remain in the manifest, methods and asset notice. No original source data are deleted or changed.

The viewer draws source parent links as lines without measured thickness, radius-derived surfaces, missing branch completion, synapses, functional connectivity or physiology. A dedicated inspector exposes graph and initial Float32 serialization diagnostics. Recentring and subsequent rendering can introduce further rounding, so the initial diagnostics do not bound total rendering error or physical accuracy. Numerical components are not cell or specimen counts.

The reference remains separate from both Digimouse models, the hindlimb and EMA147. No accepted registration, anatomical overlay or original-to-standardized transform is supplied. Physical units, calibration and anatomical direction remain unverified. Individual sex, exact age, strain, mass and explicit specimen count remain unknown. Source Male/Female and 50 to 330 day range fields do not establish individual characteristics. The source reports 15 percent shrinkage without correction; no correction is applied.

The original AA1624 candidate remains excluded because its source-specific licensing conflict is unresolved. Browser-local SWC opening remains available with its separate file-byte identity, unknown provenance and in-memory lifetime. Its user-supplied files are not bundled or uploaded.

## Provenance and distribution checks

The neuronal loader accepts only the reviewed numeric derivative, source identity, graph statistics, coordinate-frame declarations and processing records. Parser-produced assets retain exact manifest identity and immutable source values. Publication checks register the text asset while retaining ordinary privacy scanning; a failed registration does not exempt its text from review. Both source and web packaging retain required attribution and reject substituted source metadata or payloads.

The five bundled references retain their independent source namespaces and licenses. Repository and releases remain private for review. Source content checks do not resolve retained server-side commit views or authorize a visibility change.

## Verification and remaining work

The integrated reference passed all 224 JavaScript and simulated DOM cases, all 87 Python cases with the retained original inputs available, dependency notices, TypeScript and the production build. All eight loopback HTTP distribution checks passed. A conservative workspace metadata estimate plus the full WSL temporary-filesystem capacity remained below 7.1 GB, within the 10,000,000,000-byte project cap. This estimate does not inspect NTFS alternate data streams or follow symbolic links.

The integrated DOM case checks reference switching, retained backgrounds, source-bound views, observation restoration and unavailable physiology. Tests do not establish browser pixels, pointer controls, labels, responsive layout, actual file dialogs, memory use or representative GPU performance. Independent anatomical review, physical calibration, registration and quantitative physiology remain unresolved.

The development Python run executed all source comparisons with retained originals. A plain source distribution explicitly skips two neuronal converter cases and one EMA147 source-triangle comparison when their ignored original inputs are unavailable. The remaining numerical and application cases still run. No source-comparison success is inferred from a skipped case.
