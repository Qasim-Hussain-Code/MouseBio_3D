# MouseBio_3D v0.11.0

## Regional vascular and nerve references

The independently selectable MVN1 cortical vascular reference retains 575,722 edge-local point records, 12,071 sampled paths and 563,651 consecutive segments. Original topology retains 9,168 vertex identities, one numeric component and cycle rank 2,904 separately from rendering indices. All 62 zero-length segments and path-order discrepancies remain unchanged. Micrometres are source-declared without independent calibration. Effective diameters, vessel categories and simulation fields are omitted. The source is a regional mouse cortical reconstruction reused in a simulation deposit, not complete whole-body vessels or an implemented blood-flow model. See [vascular source methods](../vascular-source-assessment.md).

The independent MouseMapper predicted regional nerve reference retains all 1,940 points, 84 ordered polylines and 1,876 consecutive segments in unknown units. Its inconsistent source radius fields are omitted without inventing correspondence. Exact specimen, anatomical subregion, sex, age, diet and laterality remain unresolved. It does not supply complete adult peripheral nerves or registration to other references. The full pinned Apache License 2.0 is preserved with attribution and modification notices. See [nerve source methods](../nerve-source-assessment.md).

Both references render consecutive source links using indexed lines, without radius-derived surfaces, inferred missing branches, parent-tree conversion, smoothing, source-coordinate scaling or physiological motion. Original graph identifiers remain distinct from experimental observation structure IDs and from geometry serialization indices.

## Find anatomy

Find anatomy offers blood vessels, nerves, brain, muscles, bones, tissue layers and an independent neuronal trace through exact reviewed source selections. Choosing a topic expands source choices, coverage and limitations. A route request collapses those choices to retain space for the model. Within a source, other regions can be faded or hidden. Sources remain independent frames; no mouse overlay or registration is inferred. Failed reads or substituted source metadata retain the current reference, view and observations. Dark and White backgrounds and source-specific observation banks continue across switches.

The existing source sample explorer also binds its input draft directly to the active trace index. Source loading cannot overwrite an ID entered immediately after records appear.

## Verification and limits

The regional-polyline integration passed 272 JavaScript and simulated DOM cases, all 111 Python cases with retained original inputs, dependency notices, TypeScript, the production build and all nine loopback HTTP checks. Actual-source checks reproduce the nerve and vascular derivatives without changing the originals; the closed vascular decoder rejects serialized callables and unsupported states. Loader cases verify every ordered consecutive segment and distinguish original topology from edge-local rendering indices. Simulated workflows cover source routes, cancellation, fixed errors, faded and hidden context, white background, restored observations and rejected substitutions. Complete numeric JSON remains subject to publication privacy scans, including after failed source registration. Resource accounting remains within the 10,000,000,000-byte project cap.

An initial Chrome application workspace was observed. The runtime then stopped because it could not confidently determine the current browser URL. New graph pixels, pointer controls, representative GPU performance, memory and frame rate remain unverified. Numeric graph consistency and simulated interface tests do not establish independent anatomical accuracy, complete biological coverage or quantitative physiology.

There are seven bundled independent references and 28 scientific assets totaling 127,939,005 bytes before manifests and notices. The current package preserves source IDs, coordinate frames and individual licenses. Original code remains MIT; original documentation is CC BY 4.0 by Qasim Hussain. Digimouse-derived assets remain CC BY-SA 4.0; the regional vascular derivative is CC BY 4.0 and the MouseMapper example retains Apache-2.0 notices.
